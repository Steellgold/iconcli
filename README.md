# mkicon

Transform SVG icons into beautiful React, Vue, or Svelte components with zero config.

## Installation

```bash
npx mkicon
# or
pnpm dlx mkicon
```

## Quick Start

```bash
# Interactive mode
npx mkicon

# From URL
npx mkicon --name Arrow --url https://example.com/arrow.svg

# From clipboard
npx mkicon --name Plus --svg '<svg>...</svg>'

# Batch mode
npx mkicon --batch ./svg-folder
```
